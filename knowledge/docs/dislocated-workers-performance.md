## Learning About WIOA Performance
Performance reporting information, webinar events, and resources, and e-learning are found on [ETA's Workforce GPS website](https://performancereporting.workforcegps.org/).
The DWG program is aligned with WIOA reporting. The information found at the Workforce GPS website can help all DWG grantees!
There are resources and updated information on [ETA's performance webpage](/agencies/eta/performance/reporting).
An e-learning series highlights lessons on these required performance indicators:
* Credential Attainment
* Measurable Skill Gains
* Employment Rate
* Median Earnings
Learn more about WIOA performance reporting from the [WorkforceGPS WIOA Performance Indicators' E-Learning Series](https://performancereporting.workforcegps.org/announcements/2018/07/09/13/50/WIOA-Performance-Indicators-Summer-E-Learning-Series).
