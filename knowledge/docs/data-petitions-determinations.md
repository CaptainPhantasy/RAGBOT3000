## Petitions and Determinations Data
For workers to be eligible for TAA benefits and services, the affected group of workers must be certified as eligible to apply for TAA benefits. To begin this process, [a petition must be filed](https://www.dol.gov/agencies/eta/tradeact/petitioners) with the Department. Once a [petition is filed](https://www.dol.gov/agencies/eta/tradeact/petitioners), the Department collects information to determine if the group of workers meets the eligibility criteria.  Broadly, the information includes the name and location of the worker group, industry, number of workers, and information on the Office of Trade Adjustment Assistance (OTAA)'s determination such as when it was made, what period it covers, and under what basis we determined eligibility.
Data is available on TAA petition determinations from 1975 to Present through:
* [TAA Petition Search](https://www.dol.gov/agencies/eta/tradeact/petitioners/petitions) - This allows one to search for TAA petition status by features such as date, location, and status. This report also provides links to the redacted petition and determination document, when available.
* [Downloadable Data on Petitions](https://www.dol.gov/sites/dolgov/files/ETA/tradeact/pdfs/PetitionData_Revised.xlsx) - This downloadable Excel document provides detailed petition data for determined petitions. Data is updated monthly with a one month lag. This data is accurate as of 01/31/2023.
  + Field definitions for the file (updated 7/6/2021) are available here as a [PDF](/sites/dolgov/files/ETA/tradeact/pdfs/Petition_Data_Dictionary.pdf) and [Excel](/sites/dolgov/files/ETA/tradeact/pdfs/Petition_Data_Dictionary.xlsx).
  + [Petition statistics FAQ](https://www.dol.gov/sites/dolgov/files/ETA/tradeact/pdfs/Petition_Statistics_FAQ.pdf) explains how metrics are calculated.
* [TAA's petition data](https://dataportal.dol.gov/datasets/10249) is now available on [DOL's API portal](https://dataportal.dol.gov/).  The site includes code examples, notes on utilizing the API, data dictionaries, and more.
For any questions regarding any TAA data, please contact [taa.petition@dol.gov](mailto:taa.petition@dol.gov).
This dashboard can be used to get petition statistics for specific time periods and locations. If you are having trouble viewing this information, please download the petition dataset at the link above and use the Statistics tab to get these results.
