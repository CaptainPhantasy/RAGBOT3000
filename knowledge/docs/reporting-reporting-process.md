WIOA Performance Reporting is done at the end of each quarter when grantees submit their Quarterly Performance Report data using the [Workforce Integrated Performance System (WIPS)](/agencies/eta/performance/wips "Workforce Integrated Performance System"). The WIPS officially launched on October 1, 2016 and has been available since for users to submit data. The following resources review the system functionality from a grantee's perspective.
