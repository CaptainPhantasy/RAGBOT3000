# ETP Self-Check Tool Training Video | U.S. Department of Labor

This resource provides a video walkthrough of the ETP Self-Check Tool (see tool on [WIPS resource page](https://www.dol.gov/agencies/eta/performance/wips)). The ETP Self Check Tool is designed for users to test the Eligible Training Provider data file (ETA-9171) for potential data validity issues that would not be caught by the various edit checks in the Workforce Integrated Performance System (WIPS). In this video, users will learn how the tool functions and best practices for using the tool.
